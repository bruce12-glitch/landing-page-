01 - Strategy

Why 3D? To make invisible trust visible.

Zero-Trust = Show, Don't Say

Objectives

  • Convert CTO/CISO: "I get it in one scroll" - 6 layers mapped to 6 motions, not paragraphs.
  • Prove continuous: Motion never idles - deps drift, CVEs appear, OPA re-evaluates.
  • Prove tamper-proof: Hash -> cube -> chain - you can see immutability.
  • Keep Billow DNA: Same calm, editorial, rounded, soft-shadow system - 3D is an accent, not a carnival.

KPIs & Success

Time on layers+40s median vs current

Fallback100% meaningful if WebGL off (poster + Lottie)
Audience

Primary: CISOs, Platform Heads, Procurement Tech (India + GCC). Secondary: Vendors (need to understand "no blame, just proof").

Positioning

Billow = "Run on facts, not guesswork."
VendorChain = "Never trust. Always verify. Always prove."

Principle

Motion = explanation. If a motion doesn't clarify a layer, delete it. Max 1 hero motion + 6 layer vignettes.

Constraint

Keep Billow file's tokens, nav, cards, shadows. Only components change - same design language, new story.

04 - 3D Motion Asset System

7 assets. Each explains one lie about trust.

Spline + Three.js Lottie fallback
#1 Hero - Orbital Trust Ring

Concept

Vendor nodes (small icosahedrons) orbit a central shield. Most nodes glow blue (verified); one flickers amber then red as it's quarantined - visual proof that trust is not permanent.

Motion

Idle drift 0.08 rad/s, parallax on mouse (max 6px). Scroll 0-400px: camera dolly in 6%, nodes spread. Every 12s, one node animates: amber pulse -> OPA gate slams -> node turns red + chain link snaps.

Tech

Spline scene (2.1MB) -> <Spline scene="..."/> lazy-loaded after LCP. Fallback poster + Lottie orbit.

Verified Quarantine Blocked
#2 - ID Prism

Concept

Three stacked cards (GST, PAN, Bank) extruded with thickness. Real vendor = cards snap flush; fake vendor = cards repel with magnetic wobble + red shatter.

Motion

Flip on hover (rotateY 180deg ) to show verification checkmarks. Penny-test: 1Rs. coin drops, ripples, "Penny-test OK" stamp.

Tech

@react-three/fiber + drei RoundedBox, transmission material. Lottie fallback: card flip sequence.

State machine: idle -> flipping -> verified|rejected - driven by props, not timers.
#3 - Dependency Constellation

Concept

Force-directed graph: your app in center, 187 package nodes, edges = depends-on. Direct deps larger. Hover: highlight transitive blast radius.

Motion

On enter: nodes explode from center -> settle via physics (d3-force in 3D). Scroll scrubs: chaos -> organized tree -> diff mode (new nodes pulse blue).

Tech

Three.js Points + Lines, instanced meshes (187 instances = 1 draw call). Data from real SBOM JSON - no fake nodes.

68% weight = performance budget - this asset gets most GPU
#4 - Seal Stamp

Concept

SBOM as a paper-cube (CycloneDX icon). Cosign hammer stamps wax seal. Valid = seal glows blue + cert ribbon unfurls. Tampered = crack propagates across cube.

Motion

Stamp: 120ms down, 80ms squash, ink spread shader. Verify: seal rim lights sequentially. Tamper demo: noise displacement + crack decal.

Tech

Spline or Rive (state machine has idle -> stamping -> verified|cracked).

#5 - Risk Orb

Concept

Translucent orb whose color, size, pulse rate, and orbiting CVE shards encode the 1-10 score. Green calm 30bpm vs red frantic 120bpm - you feel risk before you read it.

Motion

Score scrub: lerpColor(#22c55e -> #ef4444) + scale 0.9->1.2 + pulse 0.5->2Hz + shard count 2->12. Uses spring mass:1, tension:180, friction:22.

Tech

Three.js ShaderMaterial (Fresnel + noise). No external AI call in canvas - score is prop from L4 card.

#6 - Gate

Concept

Artifacts on a conveyor toward an OPA gate (torii shape with Rego runes). Low risk -> gate glows green, artifact passes. High risk / no sig -> gate slams, artifact bounces, red X projects.

Motion

Gate uses rigid-body hinge (rapier). Rego toggle in UI rewires runes: risk<6 && sig.valid -> runes light in order. Fail -> runes dim one-by-one.

Tech

Three.js + Rapier (WASM, lazy). Fallback: CSS gate flap + Lottie.

#7 - Ledger Chain (Hero of Trust)

Cubes that become a chain - you watch immutability happen.

Each verdict = one translucent cube etched with truncated hash (e.g., c82e...4fb0). New cube drops from top, free-falls, magnet-snaps to chain with a soft thud + light flash. Chain gently sways like it's under tension - because it is.

Tamper demo: Try dragging a middle cube - it resists, chain flashes red, snaps back. Copy: "Only hashes are on-chain. SBOMs stay private. Try to change history - Fabric won't let you."

Block #14,821 2.1s finality 3 endorsers
Motion spec - Ledger
PropValue
Dropgravity 9.8, restitution 0.12, snap spring 280/28
Snapemissive flash 220ms, camera shake 2px

Tech: Three.js InstancedMesh (1 draw call for 24 cubes) + Rapier constraints. Fallback: stacked cards with slide-in.
Motion principles (Billow-compatible): Easing cubic-bezier(.16,1,.3,1) (same as Framer), duration 220-420ms, no infinite spins, no bounce, respects prefers-reduced-motion -> all 3D freezes to poster. Every asset has meaningful hover (not decorative) and one teachable interaction (scrub, toggle, drag, flip).

Key abstraction: <Vignette> - handles mount/unmount, DPR cap, and fallback switch so each 3D feature is ~40 lines.

function Vignette({ children, fallback }){
 const { is3D } = useCapabilities(); // WebGL + !saveData + !reducedMotion
 const ref = useInView({ rootMargin: "200px" });
 return (
 <div ref={ref} style={{minHeight: 320}}>
 {ref.inView && is3D ? children : fallback}
 </div>
 );
}
All 3D canvases capped at dpr={Math.min(devicePixelRatio, 1.8)} + frameloop="demand" - idle = 0 GPU.

  2. Low-power: WebGL 1 -> reduced shader, no physics (gate = CSS)
